How it works

Compress, index, reconstruct, verify.

NOEMA reduces raw SAR I/Q data for storage, transfer, and use in processing pipelines. Its indexed sidecar supports deterministic reconstruction of complete files or selected signal regions. Reconstruction is compared with the source using signal-level fidelity metrics. Results are dataset-dependent.

Applications

For SAR ingestion, archives, and distribution.

Compress raw SAR I/Q at ingestion, retain it in indexed archives, and distribute it to downstream users. They can download the smaller full archive or use its index to retrieve only the signal blocks they need.

Ingestion
Compress data as it enters.

Apply NOEMA to raw SAR I/Q at the ingest stage to reduce the volume moving into storage or downstream systems. Measure throughput in the target environment against the required data rate.

Archives
Store more raw SAR data.

Compress raw I/Q to reduce archive storage requirements while retaining indexed decode locations and reconstruction metadata.

Distribution
Distribute smaller archives.

Publish the compressed archive with its index for smaller full-archive downloads or retrieval and deterministic reconstruction of selected signal blocks.

Technical advantages

Deterministic decoding. Indexed access. Measured fidelity.

01 SELECTIVE DECODE

Indexed region access

Sidecar metadata maps signal regions and blocks to their decode information. Workflows can locate and reconstruct selected regions without reconstructing the complete archive.

02 SHARED METADATA

Shared codebook

One codebook can serve a batch of files, reducing overhead and keeping reconstruction behavior consistent across the archive.

03 DETERMINISTIC RECONSTRUCTION

Repeatable decoding, measured fidelity

The same compressed data and decode metadata produce the same reconstruction. Fidelity is measured against the source using SNR, normalized error, and correlation.

04 WORKFLOW COMPATIBILITY

Runs beside existing systems

Designed to run alongside recorders, archives, processors, replay tools, and analysis workflows. Validate integration and throughput in the target pipeline.

CAN RUN ALONGSIDE AN EXISTING PIPELINE
Evaluation workflow

An evaluation can run in shadow mode alongside an existing workflow. Compare compression ratio, archive-size reduction, transfer volume, and reconstruction fidelity on representative data.
